UV Mapping — built up from primitives

Three lessons, each adding one idea. Orbit with the mouse; tweak the controls on the right.

  1. A single quad & 4 UV coordinates
    UVs are just 2 numbers per vertex. Drag them, watch the texture slide.
  2. Unwrapping, seams & distortion
    See a real mesh flattened into UV space; spot where the mapping has to cheat.
  3. Beyond RGB: PBR texture channels
    Same UVs, extra images — normal / roughness / metal / AO. Fake bumps on a flat plane.
  4. Stylizing with gradient ramps
    Drive a 1-D gradient by UV / Fresnel / height to add form and highlight seams.
  5. What "sampling" actually means
    Hover the surface; watch the same (u,v) read one value from every map at once.
  6. The lighting formula, term by term
    Toggle ambient / diffuse / specular / Fresnel and watch the final pixel get assembled.

Pure HTML + Three.js (loaded from a CDN, so you need internet the first time). All textures are generated procedurally in-canvas — no asset files. Serve the folder with python -m http.server and open http://localhost:8000/, or just double-click index.html.
